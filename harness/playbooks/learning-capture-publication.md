# Playbook: Optional learning capture and publication

1. Confirm mode is `delivery+learning` and the active profile permits every proposed input.
2. Learning assessor reads only consented delivery evidence and user-authored reasoning.
3. Draft skill-specific assessment and queue changes; record that delivery nodes changed: none.
4. Offer bounded practice off the critical delivery path. Unanswered practice never blocks delivery.
5. Debriefer drafts a local Markdown summary with evidence, uncertainty, and next practice.
6. If external publication is requested, show the exact preview/destination and obtain human approval for that action.
7. Destination adapter publishes or returns failure/denial evidence. Delivery remains unchanged in all cases.

Disabling learning stops observation immediately and requires no delivery migration.
