# Project learning

Package presence is not activation. Verify the approved learning profile, then follow `../../../harness/playbooks/learning-capture-publication.md`. Learning cannot change or block delivery. Publication and consequential retention changes require human approval. The independent `learning-pack/` remains unloaded unless the user asks to study it.
