# Graph execution

For a first-call status or resume, follow `../../../harness/playbooks/status-resume.md` before any broad scan. Otherwise read only the relevant neutral playbook: `discovery-to-graph.md`, `task-dispatch.md`, `model-routing.md`, or `parallel-execution.md`. Load the pinned context revision, pending-work authority, local graph neighborhood, task brief, scoped rules, approved capabilities, and approved model-routing revision. Respect dependency readiness, exclusive write sets, isolation evidence, routing escalation triggers, and orchestrator-only graph mutation. Enforce `../../../docs/REVIEW-ROUNDS.md` for every dispatched reviewer: one initial review, at most one focused re-review, and no third unchanged loop. Write durable results through shared templates; do not store state inside `.agents/`.
