# Project learning

An explicit learning request starts configuration; it is not evidence that configuration already exists. Follow `../../../harness/playbooks/learning-capture-publication.md`. Reuse an approved learning profile when current; otherwise ask for the missing goals, observation boundary, and note destination, then record the approved configuration without credentials. Package selection is not consent. Never mutate or block the delivery graph. Public sharing and consequential retention changes require human approval. Do not load `learning-pack/` unless the user separately asks to study harness engineering.
